# Changelog

## v0.2.0 — Chrome Web Store submission candidate (2026-11-07)

- Prepared English Chrome Web Store listing, permission rationale, privacy responses and step-by-step submission checklist.
- Added automated generation of required promotional tile, store icon and first-run screenshot plus a clearly labelled synthetic-data results screenshot.
- Added version-safe release automation and CI checks for the exact runtime-only extension ZIP.
- Kept the Phase 1 permission scanner unchanged: local, on-demand and open source, with no backend or payment integration.
- **Not published in Chrome Web Store**: developer account verification, submission and Google review remain external milestones.

## v0.1.0 — Initial open-source release (2026-11-07)

- Read-only scan of installed Chrome extension declarations.
- Explainable permission exposure flags, filters, possible automation candidates and local JSON export.
- Manifest V3, optional `management` permission and no tracking / background service / cloud processing.
